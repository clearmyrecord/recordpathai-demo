# RecordPathAI Frontend v2 (staging)

This standalone preview lives under /frontend-v2/ to avoid overwriting the current RecordPathAI website or backend.

Open frontend-v2/index.html in a browser or publish this branch with GitHub Pages to preview. The public-record search is deliberately a nonfunctional demonstration; no personal records have been imported, and no API connection has been configured.

Entrepreneurship resources are at frontend-v2/resources/entrepreneurship.html. Links should be verified before production launch.

Before production: inspect existing application routes, connect only authorized record sources, implement corrections/removals and privacy protections, and test eligibility and navigation integrations.
